# Process Network Activity Viewer

Учебное настольное приложение для просмотра сетевых соединений процессов Windows.
Написано на **Java** с использованием **JavaFX**.

## Возможности

- Список TCP- и UDP-соединений с именем процесса, PID, локальными и удалёнными адресами и портами.
- Поиск и фильтрация по протоколу и порту.
- Автоматическое обновление списка каждые 5 секунд.
- Сохранение текущего снимка в памяти и сравнение его с новым состоянием.
- Отображение графика активности процесса при двойном щелчке по строке.

> **Важно:** значения «Отправлено/Получено» в текущей версии **демонстрационные**: они генерируются случайным образом и **не показывают реальный объём сетевого трафика**. Графики используют эти же демонстрационные значения.

## Требования

- **Windows** (используются системные команды `netstat -ano` и `tasklist`).
- **JDK 22** (версия проекта в конфигурации Eclipse).
- **JavaFX 21** (элементы `javafx.controls` и `javafx.fxml`).
- **Eclipse IDE** или другая Java IDE с настроенной поддержкой JavaFX.

## Запуск в Eclipse

1. Установить JDK 22 и JavaFX SDK 21.
2. Импортировать проект: **File → Import → Existing Projects into Workspace**.
3. Указать путь к папке проекта.
4. Настроить в Eclipse пользовательскую библиотеку **JavaFX21** с JAR-файлами из папки `lib` JavaFX SDK. Имя библиотеки должно совпадать с `.classpath`.
5. При необходимости добавить аргументы VM: `--module-path "ПУТЬ_К_JAVAFX_SDK/lib" --add-modules javafx.controls,javafx.fxml`.
6. Запустить `src/application/Main.java` как Java Application (с корректно настроенными JDK и JavaFX).

## Структура

- `src/application/` — исходный код, FXML-разметка и CSS-тема.
- `src/module-info.java` — модуль Java.
- `.project`, `.classpath`, `.settings/` — конфигурация Eclipse.
- `.gitignore` — исключение скомпилированных и локальных файлов из Git.

## Примечание о данных

В репозитории нет сохранённых снимков трафика или сведений о подключениях конкретного компьютера. Программа читает текущую информацию из Windows во время работы; эти сведения в репозиторий не входят.
